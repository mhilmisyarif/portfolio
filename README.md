# Portfolio

Personal portfolio of Muhammad Hilmi Syarif, AI/ML engineer focused on Natural Language Processing.

A static site: `index.html`, `styles.css` and `main.js`, with no build step. Open `index.html` in a browser to preview it, or deploy the folder as is (for example on Vercel, with no framework preset).

The recipe demo in the hero replays illustrative samples defined in `main.js`. Replace the `samples` array to show other outputs.
